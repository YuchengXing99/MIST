# MAMMOTH Biomarker Benchmark — MIST reproduction

Reproduces the 13 biomarker prediction tasks from:

> **Mixture of Mini Experts: Overcoming the Linear Layer Bottleneck in Multiple Instance Learning**
> arXiv:[2603.22198](https://arxiv.org/abs/2603.22198)

using the MIST (Molecularly Informed Spatial Transcriptomics Transform) module
and the 8 MIL baselines already registered in this repo (ABMIL, TransMIL, ILRA,
MeanMIL, MaxMIL, CLAM, TransformerMIL, DSMIL).

| TCGA-Lung     | `tcga_lung_egfr`        | `egfr_mut`         | 2       | 5     |
| TCGA-BRCA     | `tcga_brca_her2`        | `her2_status`      | 2       | 5     |
| TCGA-BRCA     | `tcga_brca_er`          | `er_status`        | 2       | 5     |
| TCGA-BRCA     | `tcga_brca_pr`          | `pr_status`        | 2       | 5     |
| TCGA-BRCA     | `tcga_brca_pik3ca`      | `pik3ca_mut`       | 2       | 5     |
| TCGA-GBMLGG   | `tcga_gbmlgg_idh1`      | `idh1_mut`         | 2       | 5     |

| BCNB          | `bcnb_pr`               | `pr_status`        | 2       | 10    |

Task keys and label dicts are registered in
`src/data_factory/cls_default.py`. Splits for the 10 TCGA tasks are generated
by `generate_biomarker_splits.py` at the repo root; run it once to populate
`src/splits/classification/biomarker/`. BCNB splits (10-fold CV per MAMMOTH)
are generated by the same script:

```bash
python generate_biomarker_splits.py bcnb /path/to/BCNB/patient-clinical-data.xlsx
```

## Data layout

Splits (`train.csv`, `val.csv`, `test.csv`) live at

```
src/splits/classification/biomarker/<task_key>_k=<fold>/
```

Each CSV has columns `case_id, slide_id, <target_col>`. TCGA-Lung draws from
both LUAD and LUSC (union of their survival-split slide lists); TCGA-GBMLGG
merges GBM + LGG. Labels come from cBioPortal:
  - mutations from `*_tcga_pan_can_atlas_2018` studies (non-silent only)
  - BRCA receptor status from `brca_tcga` (`ER_STATUS_BY_IHC`,
    `PR_STATUS_BY_IHC`, `IHC_HER2`; equivocal/indeterminate dropped)
  - IDH1 + histomolecular subtype from `lgggbm_tcga_pub`
    (IDH_STATUS + IDH_1P19Q_SUBTYPE + HISTOLOGICAL_DIAGNOSIS).

To regenerate the splits from scratch (e.g. to use a different CV seed):

```bash
python generate_biomarker_splits.py           # all 3 cohorts
python generate_biomarker_splits.py lung brca # subset
```

Features follow the repo's default (UNI-DINOv2, 20x, patch 256, dim 1536):

```
<dataroot>/extracted_mag20x_patch256_fp/extracted-vit_large_patch16_224.dinov2.uni_mass100k/feats_h5/
```

Prototypes for MIST (per-organ Spatial-Transcriptomics-derived `.npy` files)
are expected as `prototypes_k<N>.npy` inside `--proto-dir`.

## Running

One dataset, all 8 baselines + MIST variants, k=16 prototypes:

```bash
cd src
python scripts/classification/biomarker/run_sweep.py \
    --dataset tcga_lung \
    --gpus 0 1 2 3 --jobs-per-gpu 2 \
    --configs abmil abmil_mist transmil transmil_mist ilra ilra_mist \
              meanmil meanmil_mist maxmil maxmil_mist clam clam_mist \
              transformer_mil transformer_mil_mist dsmil dsmil_mist \
    --seeds 1 2 3 4 5 \
    --folds 0 1 2 3 4 \
    --n-proto 16 \
    --proto-dir /data/mol_vis_by_organ/Lung/prototypes_by_k \
    --data-root /data/TCGA-LUAD --data-root /data/TCGA-LUSC \
    --results-dir-root results_biomarker \
    --skip-existing
```

Subset of tasks:

```bash
python scripts/classification/biomarker/run_sweep.py --dataset tcga_brca \
    --tasks tcga_brca_er tcga_brca_her2 ...
```

Dry run (prints commands without launching):

```bash
python scripts/classification/biomarker/run_sweep.py --dataset bcnb --dry-run ...
```

Full 4-dataset sweep (edits required — data roots + proto dirs):

```bash
./scripts/classification/biomarker/launch_biomarker.sh
```

## Output layout

`main_classification.py` writes per-seed results as
`<results_dir>/<model_name>/seed_<seed>/summary.csv`. The sweep sets
`results_dir` to `<root>[/k<N>]/<task>/k=<fold>/` so the full tree is:

```
results_biomarker/
  k16/                         # proto sweep dir, only present for MIST configs
    tcga_lung_tp53/
      k=0/
        abmil_mist/
          seed_1/summary.csv
          seed_2/summary.csv
          ...
  tcga_lung_tp53/              # baseline configs (no k<N> prefix)
    k=0/
      abmil/
        seed_1/summary.csv
```

`--skip-existing` checks `summary.csv` presence so re-runs only do missing
jobs.

## Config matches to the paper

- Feature extractor: **UNI** (ViT-L/16 DINOv2) — matches `input_dim=1536`.
- Magnification / patch: **20x / 256** (configurable via `MAG`, `PATCH_SIZE` env).
- Epochs 20, cosine LR, AdamW lr=1e-4, wd=1e-5, grad accum 32 — inherited from
  `_run_classification_model.sh` defaults, same as the existing ABMIL/ILRA
  classification scripts in this repo.
- 5 seeds default; BCNB paper uses 10-fold CV (preset handles this).
